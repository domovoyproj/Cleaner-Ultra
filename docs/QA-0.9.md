## Автоматические проверки

- Rust: 89 обычных тестов и 4 отдельные FFmpeg-интеграции в релизной сборке. Три нативных изменяющих теста и нагрузочный benchmark не запускаются обычным набором.
- Python: 13 регрессионных тестов. Node: 16 тестов модели выбора, мастера, дерева, старой карты и закрытия диалога оптимизации; синтаксис всех JS проверен.
- Кеш/TEMP: правила известного корня, отказ полного диска и ссылок, возраст TEMP, повторная проверка файла и запущенного процесса, новые глобальные исключения перед применением, сохранённые журналы и конфликт восстановления.
- Снимок оптимизатора: 50 175 путей прочитаны порциями по 512 при параллельном удалении строк из базы; readonly WAL-снимок сохранил полный набор.

## Интерфейс

Реальное окно WebView2: светлая/тёмная темы, собственная папка с 133 файлами, вложенные Documents/Work, пустая Empty, файл в корне, выбор и сведения, раскрытие и сворачивание, подгрузка 60 → 120 из 130 файлов в Many, развёрнутое дерево и Escape. Кеш и TEMP проверены через каталог и общий список мастера. Подтверждения GUI просматриваются без удаления; реальные изменения выполняются API только по собственным фикстурам.

Снимки находятся в `qa-0.9/`. Корзина сохраняет данные на том же диске, поэтому физически освобождённый объём после переноса равен нулю. Журналы `cleanup/` нужны для восстановления.
