# Cleaner Ultra 0.7.0

Переименование приложения и расширение дискового анализатора до набора локальных инструментов обслуживания Windows.

- Rust crate/Python package: `cleaner_ultra`. Интерфейс, API-токен, окно, версия, ресурсы EXE, упаковка, установщик, CI, документация и новые корзины переименованы.
- Старое хранилище и корзины поддерживаются для восстановления. Существующие файлы не перезаписываются.
- Проверка HKCU Run/RunOnce, отключение автозагрузки и очистка отсутствующих EXE. Перед изменением сохраняются тип и точные байты; есть восстановление и проверка конфликтов.
- Список Win32-приложений с поиском, оценкой размера и штатным удалением. Код продукта MSI проверяется; произвольные команды от клиента не принимаются.
- Прогресс и дефрагментация HDD встроены в приложение через Win32 FSCTL API. Внешний `defrag.exe` удалён из действующего пути выполнения.
- Итог каждой файловой/реестровой операции и запуска удаления, журнал, длительность и JSON-экспорт. Результат фонового оптимизатора также сохраняется в журнал.

## Ограничения для ревью

- Нет поддержки TRIM и приложений Microsoft Store.
- Оптимизатор: NTFS/HDD, права администратора, завершённый снимок, до 50 000 файлов; перемещение файлов до 1 ГБ. Неподдерживаемые и занятые файлы пропускаются.
- Перенос кластеров не проверен на реальном HDD; перед релизом нужен отдельный тестовый том. Не выполнять первое испытание на пользовательских данных.
- Визуальная проверка настольного приложения не завершена: Computer Use остановлен политикой среды, которая не поддерживает URL-контроль текущего Windows-браузера.
- Репозиторий GitHub переименован в `domovoyproj/Cleaner-Ultra` через GitHub API с существующей Git-авторизацией.
- Исторические документы 0.2–0.6 описывают предыдущие версии; актуальные возможности определяются README и этим документом.

## API

GET: `/api/apps`, `/api/history`, `/api/maintenance/backups`, `/api/optimizer/status`.
POST: `/api/maintenance/scan`, `/api/maintenance/apply`, `/api/maintenance/restore`, `/api/apps/uninstall`, `/api/space/optimize`, `/api/optimizer/stop`.

Все POST требуют `X-CleanerUltra-Token`. Изменение реестра, запуск удаления и оптимизация требуют явного `confirmed: true`. Идентификаторы реестра выдаются сервером и истекают через 15 минут; произвольные пути/значения от клиента не используются.
