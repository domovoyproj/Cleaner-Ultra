CleanerUltra 0.5.0 обновляет рабочий экран для разбора больших библиотек: галерея, быстрый просмотр похожей группы и ход сканирования находятся рядом. Доступны светлая и тёмная темы. Область быстрого разбора следует выбранной папке. При сравнении двух видео появились быстрые переходы к нескольким моментам роликов.

План точных дублей теперь показывает сохраняемые файлы и все кандидаты на перенос, включая большие группы. Ничего не отмечено заранее: можно выбрать отдельные копии и проверить итоговые количество и объём перед подтверждением. Перед переносом CleanerUltra снова проверяет содержимое и наличие сохраняемой копии. Экспорт публикует файл только после проверки копии и не заменяет уже существующий файл. Если восстановление после прерванного переноса обнаружит конфликт содержимого, приложение сохранит его для проверки и покажет предупреждение.

Ошибки импорта доступны списком с причиной; выбранные файлы можно повторно обработать после окончания сканирования. Поиск по русским именам работает без учёта регистра. Запись результатов сканирования, повторные проходы и обслуживание кеша получили улучшения, которые уменьшают лишнюю работу на больших библиотеках; численные результаты зависят от коллекции и оборудования.

Доступны установщик `CleanerUltra-Setup-0.5.0-windows-x64.exe` и portable-архив `CleanerUltra-0.5.0-windows-x64.zip`. Требуются Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Установщик не подписан цифровым сертификатом.
