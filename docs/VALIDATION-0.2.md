# CleanerUltra 0.2 — проверка 8 октября 2026

Windows x64, Rust 1.99 GNU, оптимизированная release-сборка. Это результаты на машине разработки, не обещание одинакового времени на любом компьютере.

- 19 интеграционных Rust-тестов: успешно. Проверены дубли, инкрементальный импорт, отбор и отмена, постоянный журнал, конфликты восстановления, изменённые оригиналы, аварийное восстановление, экспорт, RAW+JPEG, сохранение решений, пауза/продолжение и миграция SQLite 0.1 с сохранением id и избранного. Кеш проверен также при 64 повторных генерациях превью; посторонние файлы сохраняются.
- Новый сегментный индекс сравнивался с полным перебором на 3000 отпечатках, включая повторяющиеся значения и радиусы 0, 2, 6, 12: совпадение результатов.
- 13 регрессионных Python-тестов 0.1: успешно. Python не входит в рабочую сборку 0.2.
- JavaScript приложения и Worker: `node --check` успешно.
- Через Rust API прочитаны настоящий HEIC из примеров libheif и синтетический Bayer DNG. Для обоих получены размеры и полноразмерное JPEG-превью. Это проверка декодирования, не всех моделей камер.
- Локальная MediaPipe-модель в браузерном Worker нашла одно лицо на публичном тестовом портрете; результат сохранён в SQLite без внешнего сервиса.
- В интерфейсе проверены выбор победителя с корзиной, Ctrl+Z с восстановлением, синхронный масштаб 200%, масштаб 1:1, тёмная тема и экспорт двух оригиналов. SHA-256 экспортированной копии совпал с исходным файлом.
- Нативное окно Wry открылось с заголовком CleanerUltra, отвечало на запросы и запустило дочерний WebView2. Кодеки доступны в полном дистрибутиве.
- Установка в отдельную тестовую папку и удаление завершились с кодом 0. Установленная копия прочитала HEIC/DNG. После удаления EXE отсутствует, тестовый индекс и оригиналы сохранены.

Масштабный тест `cargo test --release metadata_benchmark_100k -- --ignored --nocapture`: 100000 записей SQLite с различными 64-битными отпечатками. Группировка — **3,9896 с**, первая выдача 80 записей вместе со счётчиками — **562,9 мс**. Тест успешно завершился. Он не читает 100000 оригиналов с диска и не оценивает полный импорт RAW.

Ограничения: похожесть, смаз и закрытые глаза — подсказки, требующие визуального решения; RAW зависит от поддержки камеры и ограничен превью 8000 пикселями. Очень большие группы разбираются порциями до 200 непросмотренных файлов; перенос затрагивает показанный набор. Установщик CleanerUltra пока не подписан цифровым сертификатом. При отсутствии WebView2 официальный bootstrapper требует интернет для установки Runtime; сами фотографии обрабатываются локально.
