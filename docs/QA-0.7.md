- ReTrim через MSFT_Volume.Optimize завершился кодом 0 на NTFS SSD. Выделенный тестовый файл 8 МиБ сохранил SHA-256 и байты.
- Собственная UUID-запись HKCU Run с отсутствующим EXE очищена, восстановлена с тем же типом и байтами, затем удалена. Проверено как сервисом напрямую, так и через API релизного приложения; история сохранила две операции. Остальные записи не изменялись.

## Найдено и исправлено

- Смешанные разделители Windows ломали восстановление старой медиакорзины: нормализация и регрессия.
- Старый URL FFmpeg возвращал 404: новая закреплённая сборка, SHA-256 и зеркало.
- Начальное окно могло частично уходить за экран: явное центрирование с учётом DPI.
- Resize-зоны вызывали горизонтальную прокрутку: ограничение viewport.
- WebView2 создавал профиль рядом с EXE, упаковщик захватывал его lockfile: явный каталог профиля под данными, исключения установщика и запрет runtime-данных при упаковке.
- Общая подсказка диалога обещала отмену и для TRIM: раздельные тексты, отмена TRIM недоступна после запуска.
