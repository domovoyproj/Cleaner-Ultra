# Проверка интерфейса 0.6.1

Проверки выполнены 17 октября 2026 года на отдельном тестовом индексе. Использованы только созданные для проверки файлы в `build/`, без анализа и очистки личных папок.

| Сценарий | Проверка |
|---|---|
| Значки | Встроенные SVG отображаются в настольном окне и в браузере; проверены обзор, карта и сохранённый фоторазбор |
| Небольшой экран | На мониторе 1280×720 начальное окно помещается на экране; нижние кнопки карты доступны |
| Выбор | Одиночный щелчок выделяет папку или файл и показывает размер, долю и расположение |
| Навигация | Проверены двойной щелчок, вложенная папка, хлебные крошки и возврат к корню анализа |
| Листовая папка | Папка с одним видеофайлом показывает сам файл и долю 100%, а не пустую карту |
| Масштаб | Проверены увеличение до 150%, перетаскивание и сброс к 100% с нулевым смещением |
| Разворот | Проверены разворот в настольном окне и возврат по Escape; управление не перекрывает подписи блоков |
| Большой список | Для 132 файлов карта показывает 120 отдельных элементов и объединённый остаток; переход к остатку открывает записи 121–132 |
| Темы | Светлая и тёмная карты проверены визуально; на низком экране переключатель остаётся доступен |
| Старые данные | Автотест мигрирует индекс 0.6 без повторного анализа и проверяет последующее восстановление файла из сохранённой корзины |

В сборочном сценарии до компиляции проверяются все скрипты и пять тестов геометрии карты: пропорции, границы, отсутствие пересечений, некорректные размеры и 601 элемент. Затем выполняются Rust-проверки, включая видео. Для пакета перед публикацией повторяются запуск приложения и проверка контрольных сумм.

На этом ПК не запускались системная очистка и оптимизация реального диска. Скриншоты тестового интерфейса сохраняются локально в `build/0.6.1-*` и не включаются в репозиторий.
