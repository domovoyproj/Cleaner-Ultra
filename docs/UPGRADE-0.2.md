# CleanerUltra 0.2 — миграция и проверка

Рабочее ядро, HTTP API и настольное окно написаны на Rust. Python не требуется для запуска. JavaScript обслуживает интерфейс и локальную WASM-модель лиц.

SQLite версии 0.1 открывается без изменения идентификаторов, путей, избранного и корзины. Новые поля добавляются миграцией. Путь данных настольной версии остаётся `%LOCALAPPDATA%\CleanerUltra`. Одновременное открытие одного индекса запрещено блокировкой файла. Перед обновлением закройте 0.1. Старое приложение может читать базовые поля, но новые решения и очередь сканирования доступны в 0.2.

Новый журнал действий хранит выбор, избранное и перемещения. Ctrl+Z работает между перезапусками. Отмена восстановления снова отправляет кадр в корзину; конфликт имён сохраняет оба файла и сообщает причину. На файловых системах без hard links применяется копирование с эксклюзивным созданием, проверкой SHA-256 и синхронизацией на диск перед удалением исходной ссылки.

Сканирование сохраняет очередь в SQLite. После прерывания продолжает необработанные файлы; каталог, прерванный при перечислении, перечисляется снова без повторного добавления уже найденных файлов. Обработка идёт пакетами до 16 файлов, максимум четырьмя потоками. Пауза завершает текущие операции. Ошибки отдельных файлов доступны в прогрессе; повторный импорт повторяет их чтение. Постоянного удаления фотографий нет.

Похожие кадры используют dHash, средний и центральный отпечатки. Индекс делит 64-битный отпечаток на r+1 сегментов для радиуса r: хотя бы один сегмент соседа совпадает, после чего кандидат проверяется полным XOR/popcount. Поиск не пропускает отпечатки в заданном радиусе; визуальное сходство по-прежнему определяется эвристикой. Это эвристика: однотонные снимки могут совпадать, а сильная обрезка или сложная обработка могут не распознаться. Чувствительность регулируется. Разбор не предлагает удалять похожие файлы без выбора пользователя.

HEIC/HEIF и RAW читаются локальным ImageMagick с libheif и LibRaw. Оригиналы не перекодируются. RAW-превью ограничены 8000 пикселями по стороне и зависят от поддержки модели камеры декодером. RAW+JPEG с одинаковыми папкой и основой имени выбираются, перемещаются и экспортируются вместе. HEIC/RAW-кодеки и MediaPipe входят в полный portable-комплект и установщик.

Резкость и яркость оцениваются во время импорта. «Проверить лица» запускает локальную MediaPipe-модель в отдельном Worker для выбранных кадров или текущей страницы. Уверенная оценка моргания обоих глаз помечается «Возможно, закрыты глаза». Это подсказка, требующая визуальной проверки: модель может ошибаться при маленьких лицах, очках, поворотах и необычном освещении. Фото и результаты не отправляются в сеть. Страница с большим количеством лиц разбирается последовательно.

Кеш ограничивается настройкой в МБ. Удаляются только JPEG-превью; они восстанавливаются при следующем открытии фотографии. Данные индекса и корзины при очистке кеша сохраняются.

Экспорт копирует исходные файлы, проверяет содержимое и сохраняет структуру папок по желанию. При совпадении имени используется идентификатор кадра; если и это имя занято, операция сообщает ошибку. Экспорт не входит в Ctrl+Z, поскольку создаёт самостоятельные копии, которые пользователь мог уже изменить.

Проверки: `cargo test --locked`, `node --check cleaner_ultra/web/app.js`, `node --check cleaner_ultra/web/face-worker.js`, регрессионные Python-тесты 0.1. Масштабный тест: `cargo test --release metadata_benchmark_100k -- --ignored --nocapture`. Он проверяет группировку и выдачу страницы на 100000 записей, но не измеряет чтение 100000 оригиналов с диска. Зафиксированные измерения публикуются отдельно в отчёте проверки.
