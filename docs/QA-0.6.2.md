# Проверка 0.6.2

Проверки выполнены 17 октября 2026 года. Для файловых операций использованы только синтетические данные в `build/` и отдельный индекс `build/package-062-index`. Личные файлы и рабочий индекс пользователя не изменялись.

| Сценарий | Результат |
|---|---|
| Исключения в настольном окне | Добавлена папка «Видеопроекты» вручную, Backup.iso выбран через системный диалог файлов; оба правила сохранились |
| Светлая и тёмная темы | Диалог проверен в обеих темах; SVG, поля, кнопки и список видны; Escape закрывает диалог |
| Небольшой экран | Начальное окно 1216×624 помещается на мониторе 1280×720; раздел исключений и переключатель тем доступны |
| Применение правил | Без правил — 9 файлов / 336 МБ; исключение каталога — 7 / 166 МБ; дополнительно Backup.iso — 6 / 76 МБ |
| Повторный анализ | Запущен через настольный диалог; предупреждение об устаревших правилах исчезло, карта обновилась |
| Сохранность | Исключённые исходники не изменены; отсутствуют на новой карте |
| Карта | Выбор notes.txt, сведения о размере и пути; открытие «Архивы» двойным щелчком, отдельный ZIP в листовой папке; возврат по хлебной крошке |
| Масштаб и разворот | В настольном окне проверены 150%, перетаскивание, «Вместить» → 100%, разворот и Escape |
| Большой каталог | 132 файла: 120 блоков и объединённые 12; «Показать в списке» открывает страницу 121–132; последние файлы доступны, «Далее» отключена |
| Защита API | Тесты проверяют токен, типы входа, относительные пути, лимит, атомарность сохранения, запрет изменения во время анализа |
| Регрессии правил | Тесты проверяют границы пути, Windows-регистр, повторы, отсутствующие пути, сохранение после открытия базы, блокировку старого снимка и доступность восстановления |
| Прерванный снимок | Отдельный тест запрещает перенос по идентификатору старого снимка после ошибки нового анализа |

Локальные скриншоты: `build/0.6.2-exclusions-light.png`, `build/0.6.2-exclusions-dark.png`, `build/0.6.2-map-excluded.png`, `build/0.6.2-map-pagination.png`.

Системная оптимизация, повышение прав и необратимая очистка реального диска в рамках проверки не запускались.
