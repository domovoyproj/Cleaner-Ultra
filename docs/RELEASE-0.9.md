# Cleaner Ultra 0.9.0

## Очистка с выбором того, что оставить

- Кеш Chrome, Edge, Яндекс, Firefox, Brave, Vivaldi и Opera; кеш Discord, Slack, VS Code, Teams и старый кеш DirectX.
- TEMP пользователя и Windows старше 48 часов. Недоступный Windows TEMP показывает необходимость прав администратора.
- Все категории входят в общий мастер вместе с реестром, автозагрузкой, превью, TRIM и схемой питания. Можно исключить категорию, найти файл, снять галочку и просмотреть список перед одним подтверждением.
- Работающие программы блокируют очистку своего кеша. Cookies, пароли, история, закладки, сессии и данные сайтов не входят в правила.
- Файлы перемещаются в восстанавливаемую корзину на исходном диске. Перенесённый объём не выдаётся за освобождённое место. Восстановление не заменяет существующие файлы.

## Новый интерфейс и дерево диска

- Синяя палитра, переработанные панели, светлая и тёмная темы, отдельные разделы реестра и автозагрузки.
- Настоящее дерево папок и файлов: ветви, размеры, доли, пустые папки, клавиатура, сведения о выбранном элементе и постраничная загрузка.
- Развёрнутое дерево закрывается по Escape. Результаты очистки не затирают анализ диска.

## Исправления

- Сканирование диска показывает текущий путь и прогресс даже на длинном обходе каталогов. Недоступные элементы учитываются отдельно; ссылки на каталоги не обходятся.
- Убрано ограничение оптимизатора на 50 000 файлов. Пути читаются из стабильного снимка порциями по 512.
- Анализ диска, проверка фрагментации, дефрагментация и TRIM представлены отдельными действиями. Перед фрагментацией нужен завершённый снимок выбранного тома; диалог запуска закрывается до начала операции, включая ошибку доступа.
- Запуск больше не привязан к версии 0.7 и не держит `cargo run` открытым до закрытия приложения. Добавлен запуск без консоли через VBS.

Реестр с резервными копиями, массовая очистка несуществующих путей автозагрузки, удаление Win32-программ, отчёты и медиатека сохранены. Дефрагментация использует собственный FSCTL-движок; TRIM — прямой Windows Storage API. Внешние оптимизаторы не запускаются.

Проверены реальные диски C: и M: только на чтение, восстановление собственных тестовых файлов, интерфейс и изолированный установщик. Подробности и ограничения: [QA](QA-0.9.md). Пакеты Windows x64: установщик, portable ZIP и SHA256SUMS. Установщик без цифровой подписи. На этой машине нет механического HDD; нативное перемещение собственного NTFS-файла описано в QA 0.7.
