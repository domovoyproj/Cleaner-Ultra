Встроенный движок Cleaner Ultra

Анализ экстентов и дефрагментация через Windows FSCTL API внутри приложения. Сначала завершите анализ диска или папки. Движок обрабатывает доступные несистемные файлы из этого снимка.

Локальные диски

NTFS · для работы нужны права администратора

Дефрагментация доступна для HDD с подтверждённой задержкой поиска. SSD защищены от дефрагментации. Кнопка TRIM обращается к Windows Storage API для обработки свободных блоков. ReTrim не поддерживает отмену после запуска. Сжатые, разреженные, системные и занятые файлы пропускаются. Перенос: файлы до 1 ГБ, проверка SHA-256 до и после.

◇

Записи, которые можно объяснить

Проверка автозагрузки текущего пользователя: HKCU Run и RunOnce, 64-битное представление. Очистка доступна для однозначных ссылок на отсутствующие EXE на подключённом диске. Перед каждым изменением сохраняется тип и полное содержимое значения.

Ничего не выбрано

Нажмите «Проверить». Записи не выбираются автоматически.

Программы под контролем

Установленные Win32-программы текущего пользователя и компьютера, 32- и 64-битные записи. Cleaner Ultra запускает зарегистрированный деинсталлятор приложения. Завершите его мастер, затем обновите список. Приложения Microsoft Store здесь не перечисляются.

Каждая уборка в цифрах

Объём перенесённых файлов, результаты операций и ошибки. Файлы в восстанавливаемой корзине всё ещё занимают место; объём переноса и освобождённое место учитываются отдельно.

Что исследуем?

Выберите диск или любую папку. Анализ читает размеры и расположение файлов; содержимое остаётся на месте.

Ссылки, служебные корзины и индекс Cleaner Ultra пропускаются. Доступ к закрытым папкам может быть ограничен Windows.

ПРОВЕРЬТЕ ВЫБОР

Всё нужное осталось?

Файлы перейдут в корзину Cleaner Ultra на том же диске. Их можно восстановить. Свободное место пока не увеличится.
ВСТРОЕННАЯ ОПТИМИЗАЦИЯ

Оптимизировать диск?

Операция работает в Cleaner Ultra. Для доступа к тому нужны права администратора. Отмена останавливает обработку перед следующим файлом.
ДОСТУП К КОМПЬЮТЕРУ

Больше прав для анализа

Windows запросит разрешение UAC. После подтверждения приложение перезапустится с той же библиотекой и правами администратора. Это позволит читать больше защищённых папок. Защита системных файлов при очистке сохранится.
