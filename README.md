# Cleaner Ultra

Локальное приложение Windows 10/11 x64 для анализа дисков, восстанавливаемой очистки, обслуживания автозагрузки и удаления программ. Релиз **0.10.0**. Основной движок — Rust, интерфейс — WebView2. Python нужен только для старых регрессионных тестов.

## Возможности

- **Дерево диска:** ёмкость томов, сканирование дисков и папок, раскрываемые ветви, пустые папки, файлы, размеры и доли, клавиатура, сведения о выбранном элементе, развёрнутое дерево и пагинация каждой ветви.
- **Кеш браузеров и программ:** Chrome, Edge, Яндекс, Firefox, Brave, Vivaldi, Opera, Discord, Slack, VS Code, Teams и старый кеш DirectX. Только поддерживаемые каталоги кеша. Cookies, пароли, история, закладки, сессии и данные сайтов не включаются. Работающая программа блокирует очистку своего кеша.
- **Очистка файлов:** просмотр старого TEMP, ручной выбор до 500 файлов, повторная проверка перед переносом, SHA-256 и восстанавливаемая корзина на исходном диске. Системные файлы защищены.
- **Реестр:** отдельный от автозагрузки раздел: HKCU App Paths, COM InprocServer32/LocalServer32 и DisplayIcon программ. Только однозначные ссылки на отсутствующие EXE/DLL/OCX/ICO на подключённом диске. Исправляются отдельные значения с резервными копиями; деревья, службы, драйверы и HKLM не удаляются.
- **Мастер «Ускорить и очистить»:** TEMP пользователя/Windows, кеш браузеров/программ, битая автозагрузка, реестр, превью, TRIM и/или схема питания. Категории можно исключить заранее; затем общий список с поиском и галочками позволяет оставить конкретные файлы. Одно подтверждение, итог, частичные ошибки и JSON. TEMP старше 48 часов перемещается в восстанавливаемую корзину; DirectX — от 7 дней. Очистка не заменяет снимок диска.
- **Производительность:** живые CPU/RAM, до 40 процессов по памяти или CPU, доступная память и существующие схемы питания Windows. Предыдущая схема сохраняется до изменения и доступна для возврата. Процессы не завершаются, службы не отключаются.
- **Автозагрузка:** явное отключение выбранных записей с сохранением полного типа и байтов значения в SQLite до изменения. Восстановление не заменяет другую существующую запись. Незавершённые операции остаются доступными для восстановления. Есть «Удалить все несуществующие пути», выбор всех отсутствующих и пагинация всех резервных копий; прежнего ограничения 100 записей нет.
- **Удаление программ:** Win32-программы из HKCU/HKLM, 32/64-битные представления, поиск по названию и издателю, размер по оценке установщика, запуск зарегистрированного EXE-деинсталлятора или Windows Installer `/x` для проверенного кода продукта. Завершение удаления проверяется обновлением списка; приложения Microsoft Store не перечисляются.
- **Встроенная дефрагментация HDD:** собственный фоновый движок, прямые `FSCTL_GET_RETRIEVAL_POINTERS`, `FSCTL_GET_VOLUME_BITMAP`, `FSCTL_MOVE_FILE`. Прогресс, остановка, число проверенных/фрагментированных/обработанных файлов и SHA-256 до и после перемещения. `defrag.exe`, PowerShell и внешнее окно оптимизатора не запускаются.
- **TRIM SSD:** прямой вызов Windows Storage Management API (`MSFT_Volume.Optimize` / ReTrim) из фонового потока приложения. Windows выбирает свободные блоки; внешние утилиты не запускаются. Результат и ошибки сохраняются в истории. После запуска ReTrim отмена недоступна.
- **Итоги и история:** количество обработанных файлов/записей, объём переноса, ошибки, длительность; последние 200 операций и локальный JSON-отчёт. Перенос в корзину не выдаётся за освобождённое место.
- **Медиатека:** точные и похожие дубли фото и видео, серии, сравнение, отбор, экспорт и отдельная восстанавливаемая корзина сохранены.
- **Светлая/тёмная темы**, SVG-значки, локальный HTTP API с привязкой к loopback, проверкой Host и токеном изменения состояния.

## Границы встроенного обслуживания

Встроенный оптимизатор работает только с NTFS и подтверждённым HDD. Для анализа фрагментации/перемещения нужны права администратора и завершённый снимок выбранного диска или папки. Снимок читается порциями по 512 путей; ограничения 50 000 файлов больше нет. Перемещение ограничено файлами до 1 ГБ. Занятые, сжатые, разреженные, зашифрованные файлы и ссылки пропускаются. SSD защищены от дефрагментации. TRIM выполняется отдельной кнопкой через Windows Storage API. Карта свободных кластеров может измениться во время работы: отказ Windows отображается как ошибка, файл не удаляется.

Перенос кластеров проверен на специально фрагментированном тестовом файле NTFS с проверкой SHA-256. На этом компьютере установлены SSD: механический HDD отдельно не испытывался. Рабочий режим блокирует дефрагментацию SSD; тестовый режим перемещал только собственный файл. TRIM и сохранность выделенного тестового файла проверены на SSD. Чистка реестра не обещает ускорения Windows.

## Запуск

```powershell
cargo run --release
# Отдельные данные для разработки:
cargo run -- --browser --port 18765 --data .cleaner_ultra/dev
```

Для настольного окна нужен WebView2 Runtime. Сборка: `packaging/build.ps1`. Программа и установщик — `CleanerUltra.exe` и `CleanerUltra-Setup-0.10.0-windows-x64.exe`. `Запустить Cleaner Ultra.vbs` запускает приложение без консоли. `start.bat` выбирает текущую версию из Cargo.toml, запускает отдельным процессом и завершает свой терминал; при отсутствии пакета сначала собирает исходники.

1. Выполните анализ папки или диска. Просмотрите карту и список файлов.
2. Проверьте выбранные файлы перед переносом. В разделе «Корзина» можно вернуть их без замены существующих файлов.
3. «Реестр» или «Автозагрузка» → «Проверить» → ручной выбор → подтверждение. Резервные копии находятся ниже списка. Общая проверка доступна в «Ускорить и очистить».
4. «Удаление программ» → найдите программу → «Удалить» → завершите мастер программы → обновите список.
5. «Оптимизация» → для HDD выберите диск со снимком анализа; для SSD используйте TRIM. Прогресс и результат показываются внутри Cleaner Ultra.
6. «История и отчёты» → просмотрите итоги или сохраните JSON. Отчёт содержит локальные пути; перед передачей другому человеку проверьте его.

## Данные и обновление

Новые установки используют `%LOCALAPPDATA%\CleanerUltra`. Если новой папки ещё нет, но присутствует `%LOCALAPPDATA%\PhotoSort`, приложение продолжает использовать старую библиотеку, не копируя и не удаляя её. Параметр `--data` имеет приоритет.

`space.sqlite3` — дисковый снимок и корзина, `library.sqlite3` — медиатека, `maintenance.sqlite3` — резервные копии реестра и история, `cleanup/` — отдельные журналы кеша и TEMP. Эти данные нужны для восстановления. Не удаляйте базы вместе с файлами `-wal`/`-shm`, пока приложение работает.

Новые корзины: `.cleaner_ultra-space-trash` и `.cleaner_ultra-trash`. Старые `.photosort-space-trash` и `.photosort-trash` пропускаются сканированием и поддерживаются при восстановлении старых журналов. Старое имя оставлено только для совместимости и тестов миграции. Репозиторий переименован в [domovoyproj/Cleaner-Ultra](https://github.com/domovoyproj/Cleaner-Ultra).

## Разработка и проверки

```powershell
cargo test --locked
python -m unittest discover -s tests -v
node --check cleaner_ultra/web/app.js
node --check cleaner_ultra/web/space.js
node --check cleaner_ultra/web/maintenance.js
node --check cleaner_ultra/web/face-worker.js
node --check cleaner_ultra/web/icons.js
node --test tests/map-layout.cjs tests/cleanup-plan.cjs tests/wizard.cjs tests/disk-tree.cjs tests/optimizer-ui.cjs
```

Для небольшого окна доступны `--width 960 --height 720`; размеры ограничиваются экраном. Профиль WebView2 хранится внутри выбранного каталога данных и не попадает в portable-архив. Установщик пока без цифровой подписи.

При отсутствии MSVC используйте установленный Rust GNU и MinGW в PATH. `cargo +stable-x86_64-pc-windows-msvc fmt` можно применять независимо от выбранного компилятора. FFmpeg-интеграции запускаются отдельно при наличии кодеков; `packaging/build.ps1` включает их в релизную проверку.

Код: `src/space.rs` — диски и корзина, `maintenance.rs` — реестр и история, `apps.rs` — программы, `optimizer.rs` — встроенный движок HDD, `trim.rs` — Windows ReTrim, `compat.rs` — совместимость, `library.rs`/`analysis.rs`/`video.rs` — медиа, `server.rs` — API, `main.rs` — окно. Интерфейс: `cleaner_ultra/web`.

Использован [ai-mega-prompt](https://github.com/domovoyproj/ai-mega-prompt/blob/main/MEGA-PROMPT.md): исследование существующего стека, точечные изменения, проверяемый результат и явные ограничения. Graphify MCP не имеет доступных рабочих пространств; локальный CLI отсутствует. Архитектура проверена через исходники, импорты и тесты. Дополнительные навыки и платные сервисы не устанавливались.
