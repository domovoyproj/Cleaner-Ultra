# PhotoSort Space

Приложение для Windows, которое показывает, что занимает место на компьютере, и помогает навести порядок. Анализ дисков — основная задача; прежний PhotoSort для фото и видео сохранён как отдельный инструмент очистки медиатеки.

[Скачать последнюю версию](https://github.com/domovoyproj/PhotoSort/releases/latest) · [Изменения](CHANGELOG.md) · [Концепция 0.6](docs/RELEASE-0.6.md)

## Возможности

- **Обзор дисков:** реальные ёмкость, занятое и свободное место локальных томов. Анализ диска или отдельной папки.
- **Карта папок:** папки и отдельные файлы с точными пропорциями, выбор и сведения об элементе, двойной щелчок для перехода внутрь, хлебные крошки. Масштаб 100–400%, перетаскивание, «Вместить» и разворот карты.
- **Пути-исключения:** папки со всем содержимым и отдельные файлы, выбор через Проводник или полный путь. Правила сохраняются между запусками и применяются при новом анализе. После изменения правил очистка старого снимка блокируется до повторного анализа.
- **Все типы файлов:** фоновое сканирование без декодирования медиа, пакетная запись в SQLite, поиск по имени с поддержкой кириллицы, фильтры и Проводник.
- **Осознанная очистка:** старые файлы TEMP, ручной выбор, полный список перед переносом. Системные каталоги и рабочие файлы приложения защищены.
- **Восстанавливаемая корзина:** проверка SHA-256, журнал переносов, восстановление без перезаписи. Корзина находится на исходном диске и продолжает занимать место. Для системной очистки и удаления приложений доступны инструменты Windows.
- **Оптимизация дисков:** анализ фрагментации и запуск подходящей оптимизации HDD/SSD через Windows `defrag /O`. Только явный запуск с запросом прав администратора; ход и результат видны в системном окне.
- **Режим администратора:** настольное приложение может перезапуститься через UAC с той же библиотекой для чтения защищённых папок. Повышение прав не отключает защиту системных файлов от очистки.
- **Фото и видео:** похожие кадры, серии, точные дубли, отбор, сравнение, воспроизведение роликов, экспорт и прежняя корзина сохранены.
- **Монохромный интерфейс:** SVG-значки без зависимости от шрифтов, светлая и тёмная темы, три кнопки окна, локальная работа на Rust. Python для запуска не нужен.

## Установка и работа

Скачайте установщик `PhotoSort-Setup-<версия>-windows-x64.exe` или распакуйте portable-архив целиком и запустите `PhotoSort.exe`. Нужны Windows 10/11 x64 и WebView2 Runtime. Установщик предложит установить WebView2 при его отсутствии; для этого потребуется интернет. Цифровой подписи установщика пока нет.

1. Выберите диск и нажмите «Анализировать диск», либо выберите папку через «＋».
2. Откройте карту папок или крупные файлы. Неполный анализ и недоступные элементы отмечены явно.
3. Проверьте выбранные пути и размеры, затем перенесите ненужное в корзину PhotoSort. Файлы можно вернуть из раздела «Корзина».
4. Для освобождения места за счёт системных временных файлов, удаления приложений и очистки корзины Windows используйте системные инструменты из раздела «Очистка».
5. Для медиатеки откройте «Фото и видео». Добавьте папку, сравните кадры и просмотрите план дублей. Сохраняемые копии повторно проверяются перед переносом.

Размеры в карте — логические размеры файлов. Жёсткие ссылки, сжатие, разреженные файлы и закрытые системные папки могут давать отличие от занятого места тома. Остановка анализа сохраняет частичный результат; новый анализ строит свежий снимок. Автоматической очистки реестра, отключения служб и удаления системных компонентов нет.

## Данные и форматы

Данные находятся в `%LOCALAPPDATA%\PhotoSort`. Новый анализ использует `space.sqlite3`, прежняя медиатека — `library.sqlite3`. Не удаляйте индекс, пока в корзине есть файлы. Корзины `.photosort-space-trash` и `.photosort-trash` находятся внутри исходной области. Индекс, история переносов и оригиналы не удаляются при очистке кеша превью.

Дисковый анализ считает любые обычные файлы. Медиатека читает JPEG, PNG, WebP, TIFF и BMP; Windows-сборка содержит декодеры HEIC/HEIF, AVIF и распространённых RAW-форматов. Поддержка камеры зависит от декодера. Видео: MP4/M4V, MOV, MKV, AVI, WebM, WMV, MTS/M2TS, MPG/MPEG при читаемой видеодорожке. Доступно совместимое WebM-превью, оригинал сохраняется. [Видео и ограничения](docs/VIDEO-0.3.md).

## Разработка

Нужны Rust, Node.js и Windows C++ toolchain. На этой машине без MSVC используется `cargo +stable-x86_64-pc-windows-gnu`, а `.photosort/tools/mingw/mingw64/bin` добавляется в PATH.

```powershell
python -m pip install -r requirements-dev.txt
./packaging/prepare-runtime.ps1
./packaging/fetch-ffmpeg.ps1
cargo test --locked
cargo test --locked video_ -- --ignored
python -m unittest discover -s tests -v
node --check photosort/web/space.js
node --check photosort/web/icons.js
node --test tests/map-layout.cjs
node --check photosort/web/app.js
node --check photosort/web/face-worker.js
./packaging/build.ps1
```

`cargo run --release` открывает приложение. `cargo run -- --browser --port 18765 --data .photosort/dev` запускает локальный сервер с отдельным индексом: обзор по `/`, медиатека по `/photos`. `start.bat` открывает локальную сборку 0.6.2.

`src/space.rs` — дисковый анализ, карта, корзина и инструменты Windows; `src/library.rs` — медиатека; `src/analysis.rs` — декодирование и отпечатки; `src/video.rs` — видео; `src/server.rs` — API; `src/main.rs` — окно. Новый интерфейс — `photosort/web/space.*`, медиатека — `index.html`, `app.js`, `style.css`, `update.css`. Python-модули сохранены для проверки миграции.

Для связей кода используйте `graphify query`, `graphify affected`, `graphify god-nodes`, `graphify explain`. После изменений: `graphify extract . --code-only`. При неисправном Windows launcher: `.venv/Scripts/python.exe -m graphify extract C:\momp\PhotoSort --code-only --out C:\momp\PhotoSort`. `graphify-out/`, пользовательские файлы, `target/`, `dist/` и окружения исключены из Git.
