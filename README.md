# Cleaner Ultra

Локальное приложение Windows 10/11 x64 для анализа дисков, восстанавливаемой очистки, обслуживания автозагрузки и удаления программ. Версия разработки **0.7.0**. Основной движок — Rust, интерфейс — WebView2. Python нужен только для старых регрессионных тестов.

## Возможности

- **Диски и карта:** ёмкость томов, сканирование папок, все типы файлов, крупные файлы, поиск, категории, исключения, масштабируемая карта с переходами и пагинацией.
- **Очистка файлов:** просмотр старого TEMP, ручной выбор до 500 файлов, повторная проверка перед переносом, SHA-256 и восстанавливаемая корзина на исходном диске. Системные файлы защищены.
- **Реестр:** проверка значений `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и `RunOnce` в 64-битном представлении. Очистка однозначных ссылок на отсутствующие EXE; остальные команды доступны для ручной проверки. Нет удаления деревьев реестра, служб, драйверов, COM и записей HKLM.
- **Автозагрузка:** явное отключение выбранных записей с сохранением полного типа и байтов значения в SQLite до изменения. Восстановление не заменяет другую существующую запись. Незавершённые операции остаются доступными для восстановления.
- **Удаление программ:** Win32-программы из HKCU/HKLM, 32/64-битные представления, поиск по названию и издателю, размер по оценке установщика, запуск зарегистрированного EXE-деинсталлятора или Windows Installer `/x` для проверенного кода продукта. Завершение удаления проверяется обновлением списка; приложения Microsoft Store не перечисляются.
- **Встроенная дефрагментация HDD:** собственный фоновый движок, прямые `FSCTL_GET_RETRIEVAL_POINTERS`, `FSCTL_GET_VOLUME_BITMAP`, `FSCTL_MOVE_FILE`. Прогресс, остановка, число проверенных/фрагментированных/обработанных файлов и SHA-256 до и после перемещения. `defrag.exe`, PowerShell и внешнее окно оптимизатора не запускаются.
- **Итоги и история:** количество обработанных файлов/записей, объём переноса, ошибки, длительность; последние 200 операций и локальный JSON-отчёт. Перенос в корзину не выдаётся за освобождённое место.
- **Медиатека:** точные и похожие дубли фото и видео, серии, сравнение, отбор, экспорт и отдельная восстанавливаемая корзина сохранены.
- **Светлая/тёмная темы**, SVG-значки, локальный HTTP API с привязкой к loopback, проверкой Host и токеном изменения состояния.

## Важные границы версии 0.7

Встроенный оптимизатор работает только с NTFS и подтверждённым HDD. Для анализа/перемещения нужны права администратора и завершённый снимок диска или папки. Обрабатываются до 50 000 доступных несистемных файлов из снимка; перемещение ограничено файлами до 1 ГБ. Занятые, сжатые, разреженные, зашифрованные файлы и ссылки пропускаются. SSD защищены от дефрагментации. **TRIM пока не реализован.** Карта свободных кластеров может измениться во время работы: отказ Windows отображается как ошибка, файл не удаляется.

Перемещение кластеров на реальном HDD ещё требует проверки на отдельном тестовом NTFS-томе; это версия для ревью, не готовый проверенный релиз. Факт сборки и прохождения тестов не подтверждает работу драйвера хранения. Чистка реестра не обещает ускорения Windows.

## Запуск

```powershell
cargo run --release
# Отдельные данные для разработки:
cargo run -- --browser --port 18765 --data .cleaner_ultra/dev
```

Для настольного окна нужен WebView2 Runtime. Сборка: `packaging/build.ps1`. Имя программы и установщика — `CleanerUltra.exe` и `CleanerUltra-Setup-0.7.0-windows-x64.exe`; отображаемое имя — **Cleaner Ultra**. `start.bat` запускает установленную в `dist` сборку либо собирает исходники.

1. Выполните анализ папки или диска. Просмотрите карту и список файлов.
2. Проверьте выбранные файлы перед переносом. В разделе «Корзина» можно вернуть их без замены существующих файлов.
3. «Реестр и автозагрузка» → «Проверить» → ручной выбор → подтверждение. Резервные копии находятся ниже списка.
4. «Удаление программ» → найдите программу → «Удалить» → завершите мастер программы → обновите список.
5. «Оптимизация» → выберите диск со снимком анализа. Прогресс и результат показываются внутри Cleaner Ultra.
6. «История и отчёты» → просмотрите итоги или сохраните JSON. Отчёт содержит локальные пути; перед передачей другому человеку проверьте его.

## Данные и обновление

Новые установки используют `%LOCALAPPDATA%\CleanerUltra`. Если новой папки ещё нет, но присутствует `%LOCALAPPDATA%\PhotoSort`, приложение продолжает использовать старую библиотеку, не копируя и не удаляя её. Параметр `--data` имеет приоритет.

`space.sqlite3` — дисковый снимок и корзина, `library.sqlite3` — медиатека, `maintenance.sqlite3` — резервные копии реестра и история. Все три базы нужны для восстановления. Не удаляйте базы вместе с файлами `-wal`/`-shm`, пока приложение работает.

Новые корзины: `.cleaner_ultra-space-trash` и `.cleaner_ultra-trash`. Старые `.photosort-space-trash` и `.photosort-trash` пропускаются сканированием и поддерживаются при восстановлении старых журналов. Старое имя оставлено только в коде совместимости, тестах миграции и действующем URL GitHub. Репозиторий на GitHub пока остаётся [domovoyproj/PhotoSort](https://github.com/domovoyproj/PhotoSort); его переименование требует доступного интерфейса настроек GitHub.

## Разработка и проверки

```powershell
cargo test --locked
python -m unittest discover -s tests -v
node --check cleaner_ultra/web/app.js
node --check cleaner_ultra/web/space.js
node --check cleaner_ultra/web/maintenance.js
node --check cleaner_ultra/web/face-worker.js
node --check cleaner_ultra/web/icons.js
node --test tests/map-layout.cjs
```

При отсутствии MSVC используйте установленный Rust GNU и MinGW в PATH. `cargo +stable-x86_64-pc-windows-msvc fmt` можно применять независимо от выбранного компилятора. FFmpeg-интеграции запускаются отдельно при наличии кодеков; `packaging/build.ps1` включает их в релизную проверку.

Код: `src/space.rs` — диски и корзина, `maintenance.rs` — реестр и история, `apps.rs` — программы, `optimizer.rs` — встроенный движок HDD, `compat.rs` — совместимость, `library.rs`/`analysis.rs`/`video.rs` — медиа, `server.rs` — API, `main.rs` — окно. Интерфейс: `cleaner_ultra/web`.

Использован [ai-mega-prompt](https://github.com/domovoyproj/ai-mega-prompt/blob/main/MEGA-PROMPT.md): исследование существующего стека, точечные изменения, проверяемый результат и явные ограничения. Graphify MCP не имеет доступных рабочих пространств; локальный CLI отсутствует. Архитектура проверена через исходники, импорты и тесты. Дополнительные навыки и платные сервисы не устанавливались.
