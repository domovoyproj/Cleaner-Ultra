# PhotoSort

PhotoSort помогает разобрать большую папку фотографий и видео на Windows. Приложение находит точные дубли, собирает похожие кадры и серии, показывает файлы без решения и помогает выбрать, что оставить. Оригиналы хранятся на вашем устройстве.

[Скачать PhotoSort 0.5.0](https://github.com/domovoyproj/PhotoSort/releases/tag/v0.5.0) · [История изменений](CHANGELOG.md)

## Возможности

- **Быстрый просмотр:** превью, сравнение двух файлов, синхронный масштаб для фото, воспроизведение видео и переход к нескольким моментам сравниваемых роликов.
- **Разбор коллекции:** похожие кадры, серии по времени съёмки, точные дубли SHA-256 и раздел «Не разобраны».
- **Удобная навигация:** поиск по имени без учёта регистра, в том числе по кириллице; сортировка, отдельные разделы фото и видео, фильтр по добавленной папке. Библиотека, быстрый разбор и ход сканирования видны на одном экране.
- **Выбор лучших:** избранное, решения «оставить», «отклонить» и «пропустить». Можно продолжить разбор после перезапуска.
- **Безопасные файловые операции:** полный план точных дублей с выбором отдельных файлов, экспорт проверенных копий, корзина в исходной папке, восстановление без перезаписи существующих файлов и отмена через Ctrl+Z. Автоматического безвозвратного удаления нет.
- **Контроль импорта:** прогресс и пауза сканирования, список файлов с ошибками и повтор выбранных после окончания прохода.
- **Локальная работа:** Rust-ядро, SQLite, светлая и тёмная темы. Сетевой сервис для анализа файлов не требуется.

## Установка

Загрузите `PhotoSort-Setup-0.5.0-windows-x64.exe` со страницы релиза. Для запуска без установки распакуйте `PhotoSort-0.5.0-windows-x64.zip` целиком и откройте `PhotoSort.exe`.

Нужны Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. Установщик предложит поставить WebView2, если его нет; для этого нужен интернет. Python для запуска не нужен. Установщик пока не подписан цифровым сертификатом.

## Как разбирать файлы

1. Добавьте папку с фото и видео. Вложенные папки сканируются параллельно. Ход работы виден над галереей; сканирование можно поставить на паузу и продолжить после перезапуска. Если файл не обработан, откройте список ошибок и повторите выбранные файлы после окончания прохода.
2. Откройте «Не разобраны», «Похожие кадры», «Серии» или «Точные дубли». Если добавлено несколько папок, ограничьте галерею нужной папкой через фильтр над файлами. Панель быстрого разбора показывает область выбранной папки.
3. В просмотре используйте P — оставить, X — отклонить, S — пропустить. Можно отметить два файла и сравнить их рядом. Отклонение само по себе не перемещает файл.
4. «Разобрать дубли» откроет полный план: сохраняемые копии, кандидаты на перенос и их размер. Файлы изначально не выбраны. Просмотрите план, отметьте нужные копии и проверьте итоговые количество и объём перед подтверждением. Приложение повторно проверяет содержимое и защищает избранное.
5. Экспортируйте выбранные оригиналы или переместите ненужные файлы в корзину. Экспорт сначала проверяет временную копию, затем публикует её без замены существующего файла. Восстановление тоже оставляет существующий файл нетронутым, если его имя уже занято.

RAW и JPEG с одинаковой основой имени выбираются и экспортируются вместе. Для видео с кодеком, который WebView2 не воспроизводит, доступно локальное совместимое превью WebM; оригинал не меняется. [Форматы и ограничения видео](docs/VIDEO-0.3.md).

## Форматы и данные

Rust читает JPEG, PNG, WebP, TIFF и BMP. Полная Windows-сборка содержит локальные декодеры для HEIC/HEIF, AVIF и распространённых RAW-форматов; поддержка конкретной камеры зависит от декодера. Видео: MP4/M4V, MOV, MKV, AVI, WebM, WMV, MTS/M2TS, MPG/MPEG при наличии читаемой видеодорожки.

Сходство фото определяется визуальными отпечатками; сходство видео — тремя кадрами, соотношением сторон и длительностью. Это подсказка для просмотра, поэтому решение о переносе остаётся за вами. Точные дубли сравниваются по SHA-256 целого файла.

Библиотека настольной версии находится в `%LOCALAPPDATA%\PhotoSort`. При обновлении индекс старых версий мигрирует с сохранением избранного, путей и корзины. Закройте старое окно перед обновлением. Корзина хранит файлы в `.photosort-trash` внутри исходной папки. Не удаляйте индекс и журнал вручную, пока в корзине есть файлы. Если прерванная операция оставила неоднозначное состояние, приложение покажет предупреждение и сохранит запись в журнале для проверки. Кеш превью ограничен настройкой и восстанавливается по мере необходимости.

## Разработка

Нужны Rust, Node.js для проверки интерфейса и Windows C++ toolchain. Для полного комплекта локальных декодеров и установщика запустите сборочный сценарий:

```powershell
python -m pip install -r requirements-dev.txt
./packaging/prepare-runtime.ps1
./packaging/fetch-ffmpeg.ps1
cargo test --locked
cargo test --locked video_ -- --ignored
python -m unittest discover -s tests -v
node --check photosort/web/app.js
node --check photosort/web/face-worker.js
./packaging/build.ps1
```

`cargo run --release` запускает окно; `cargo run -- --browser --port 18765 --data .photosort/dev` — отдельную библиотеку в браузере. На Windows без MSVC используется `cargo +stable-x86_64-pc-windows-gnu` и каталог `.photosort/tools/mingw/mingw64/bin` в PATH. `start.bat` открывает собранную версию из `dist/PhotoSort-0.5.0`.

`src/library.rs` отвечает за индекс, очередь и файловые операции; `src/analysis.rs` — за декодирование и отпечатки; `src/video.rs` — за видео; `src/server.rs` — за локальный API; `src/main.rs` — за окно. Интерфейс находится в `photosort/web/`. Python-модули сохранены для проверки миграции старых библиотек и не используются рабочей версией.

Перед изменением связанного кода используйте Graphify: `graphify query`, `graphify affected`, `graphify god-nodes` и `graphify explain`. После изменений обновите граф командой `graphify extract . --code-only`. На этой машине при неисправном Windows launcher подходит `.venv/Scripts/python.exe -m graphify extract C:\momp\PhotoSort --code-only --out C:\momp\PhotoSort`. `graphify-out/`, пользовательские медиа, окружение, `target/` и `dist/` исключены из Git.
